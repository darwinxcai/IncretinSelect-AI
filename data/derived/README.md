# Derived data

Generated structure manifests, split assignments, features, predictions, and
compact audit tables belong here. Raw workbooks, the full P1–P15 holdout JSON, and
the 90-row replicate-level sensitivity table remain gitignored. The released
45-row evaluation table is peptide-endpoint level and retains exact/bound status.

Checked-in release artifacts:

- `sequence_clusters.csv`: connected components at the frozen 0.85 identity rule;
- `outer_folds.csv`: deterministic, cluster-intact 3-fold assignments;
- `cluster_threshold_audit.csv`: all predeclared threshold candidates;
- `baseline_oof_predictions.csv`: training-only tied 1-NN and median predictions.
- `sequence_model_oof_predictions.csv`: nested, component-aware ridge predictions
  and matched tied 1-NN predictions on the same outer folds.
- `structures.csv`: resolved RCSB metadata for the 10-entry experimental
  peptide–GPCR seed panel, including receptor and peptide entity chains.
- `cpu_sequence_model_figure_source.csv`: 250 receptor-specific OOF plotting rows
  plus three whole-component bootstrap comparison rows used by the release figure.
- `external_predictions_locked.csv`: 15 label-independent final-model predictions
  committed before the outcome-scoring command.
- `external_dependency_groups.csv`: frozen external-only, nearest-donor proxy, and
  combined development/external dependence assignments.
- `external_evaluation_records.csv`: 45 auditable peptide-endpoint observations
  with aggregate exact/bound targets, predictions, and constraint losses.
- `external_evaluation_figure_source.csv`: 22 model-metric and dependence-aware
  contrast rows used by the external-evaluation PNG/SVG.

The development artifacts are regenerated by `scripts/freeze_sequence_splits.py`
or one of the two CPU model scripts. External predictions were produced by the
locked preparation command and scored exactly once from the recorded lock commit;
`scripts/plot_external_evaluation.py` only rebuilds the post-score figure and its
source table. Source, configuration, and implementation checksums are stored in
the corresponding JSON receipts. These derived tables retain the upstream
experimental dataset's CC BY 4.0 attribution requirements; see
`../../DATA_LICENSE.md`.
