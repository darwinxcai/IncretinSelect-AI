Browser application · ridge regression · research use

IncretinSelect-AI

Estimate cell-based cAMP EC50 at GLP-1R and GCGR for incretin-like peptide sequences, with an explicit assessment of when the model should and should not be used.

Local processing Calculations and imported files remain in this browser. There is no backend, account, analytics service, or network transmission of sequences.
Scope: sequence-based research estimates of cell-based cAMP EC50. Outputs do not measure binding affinity, maximal assay response, safety, or in vivo activity and do not constitute candidate recommendations.

How automatic mapping works

Automatic mapping is accepted only when all best-scoring reference-guided mappings agree and the mapped sequence is at least 85% identical to the reference panel. The 85% gate is a software scope rule, not a confidence estimate. Use Expert mode only for a reviewed 30-column alignment.

One sequence only; importing a file never sends it to a server.

Preferred columns: candidate_id,sequence for raw 26–30-residue inputs. The legacy expert schema candidate_id,aligned_sequence remains supported. Maximum 200 raw-sequence or 500 expert-alignment candidates, and 2 MB. Every invalid or out-of-scope row remains visible in the downloaded result.

Screening objective

Select a ranking objective. Lower predicted EC50 ranks first; only inputs meeting the ≥0.85 identity and ≥26-residue criteria are ordered. Passing these gates does not establish prediction accuracy.

Supported inputs and chemistry

This sequence-only model accepts canonical 26–30-residue peptides. It cannot represent Aib, lipidation, amidation, cyclization, stapling, D-amino acids, or other noncanonical chemistry. Structure files are not supported because the model uses no structural features.
